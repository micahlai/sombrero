    Make the graph move.

    Event buttons queue requests. Boolean checkboxes remain set until you change them. Each petting session finishes its first full animation cycle before taking a release/event exit. After that, exits interrupt immediately; held pet animations loop at clip end. Dialogue open forces Pet off, and hover can resume only after closing it. Recall weights (4C top / 4B screen / 4B window side): neither clearance 0/100/0%; top only 80/20/0%; side only 0/50/50%; both 40/40/20%. Window-side entry detaches after 4B; top entry stays attached until dragged. Red routes interrupt immediately; purple routes wait for the current animation to finish.

    When the current state has multiple weighted default exits, click one of its directly connected destination nodes to force the next roll (weight 1 for that route, 0 for the others). It waits for clip completion and never overrides conditional routes. The chosen node is labeled Next roll and its route is highlighted on the diagram. Click the node again to cancel. The override clears after one transition.

    Other node clicks inspect only. Choose Solo clip to loop one animation without state transitions. Play this state remains an explicit debug jump.

    Put numbered PNG, WebP, JPEG or AVIF frames inside assets/duck/final-v1/1A/, 1B/, etc. Folder IDs ignore case; frames use natural filename order. Then click Reload assets. Missing, empty, or unreadable animations are labeled on the graph and play ten pink-square frames.

    Use scale map applies the reviewed clip-level transforms in final-v1/animation-scales.json. Turn it off to compare original framing. Source frames are never rewritten.
